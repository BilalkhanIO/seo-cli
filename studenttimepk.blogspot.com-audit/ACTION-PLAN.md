# Action Plan — studenttimepk.blogspot.com

Ordered by impact ÷ effort. Do the top two first — they touch all 143 posts.

## 🔴 Do now (highest impact)

1. **Add meta descriptions to posts** — *effort: ongoing, per post*
   Blogger → each Post → **Search Description** (140–155 chars, include the target keyword).
   Start with your 10–15 highest-traffic posts, then work down the list.
   → First enable **Settings → Meta tags → Enable search description**.

2. **Fix the H1 / heading hierarchy** — *effort: one-time theme edit*
   Make the post title the `<h1>` (currently the blog name is H1 and the title is H3).
   Either edit the theme HTML (`<data:post.title/>` → wrap in `<h1>`) or switch to a
   modern SEO-optimized Blogger theme. This single fix corrects all 143 posts at once.
